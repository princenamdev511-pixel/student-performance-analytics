# Student Performance Analytics System

A basic Python project for analyzing student marks using NumPy and Pandas.

## Technologies Used
- Python
- NumPy
- Pandas

## Features
- Read student data from CSV
- Calculate total and average marks
- Assign grades
- Check Pass/Fail
- Analyze subject-wise performance
- Find top-performing students

## Dataset
The dataset contains 20 student records with marks, department and attendance details.

## How to Run

```bash
pip install pandas numpy
python main.py
