## 3. Objective

The objective of this project is to analyze student performance using Python, NumPy and Pandas.
The project reads student marks from a CSV file and calculates total marks, average marks, grades and pass/fail results.

## 4. Technologies Used

- Python
- NumPy
- Pandas

## 5. Dataset Description

The dataset contains 20 student records.
The columns are:

- Student ID
- Name
- Department
- Python
- NumPy
- Pandas
- English
- Attendance

## 6. Implementation

First, the CSV file is read using Pandas.
Then functions are used to calculate total marks, average marks, grades and pass/fail status.
NumPy is used for numerical calculations and averages.
Loops and conditions are used for pass/fail counting and finding the best subject.
Pandas is used to add new columns and perform basic analysis.

## 7. Key Features

- Student data display
- Total marks
- Average marks
- Grade
- Pass/Fail
- Class average
- Highest performance
- Lowest performance
- Subject-wise average
- Best subject
- Top 3 students
